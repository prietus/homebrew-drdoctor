# Homebrew Tap for DrDoctor

Audio mastering analyzer for macOS: DR14 dynamic range, loudness, true peak and clipping, spectral analysis with fake lossless detection, and stereo image. Reads DSF, FLAC, WAV, AIFF, ALAC, MP3 and AAC.

## Install

```bash
brew tap prietus/drdoctor
brew install --cask drdoctor
```

## Requirements

- macOS 14+ (Sonoma)
